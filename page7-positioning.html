position: static

static

The default value — the element sits in the normal document flow, and the top/left properties have no effect on it.

position: relative

relative

The box is shifted by top: 15px; left: 30px relative to its original position, but the space it would have occupied is still "reserved" (the dashed border stays the same size).

position: absolute

absolute

The box left the normal flow and anchored itself to the top-right corner of its parent element with position: relative (the red border), instead of the whole page.

position: fixed vs position: sticky

The yellow box in the bottom-right corner of the screen has position: fixed — scroll the page down, and it will always stay in the same place relative to the browser window, regardless of scrolling.

fixed

The purple box below has position: sticky. It "sticks" to the top only within its own container — scroll the gray container down, and the purple box will stop near the top of the container instead of moving with the whole page like fixed does.

fixed vs sticky in short

fixed is always anchored to the browser window, ignoring any scrolling and any parent. sticky behaves like a normal element until scrolling reaches the given top, and then it "sticks", but only within its nearest scrollable or height-limited container; once it moves past that container, the sticky element scrolls along with it.
