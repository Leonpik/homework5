Task 6. The overflow Property

All the containers below have the same text, longer than the box size (width: 250px; height: 100px), but the behavior differs.

overflow: visible (default value)

Text that doesn't fit simply spills outside the container and overlaps neighboring content, while the container's own size stays unchanged.

overflow: hidden

Text that doesn't fit is clipped and fully hidden — no scrollbar appears, and there is no way to see the extra text.

overflow: scroll

Scrollbars always appear, even if the content actually fits completely — both horizontally and vertically.

overflow: auto

A scrollbar appears only when the content actually doesn't fit in the box — this is the most "smart" option of the four.
