Task 2. Block and Inline Elements

Block divs

Each <div> is a block element: it takes up the full width of its container and starts on a new line, even if there is little content inside.

Inline spans

Here span one, span two and span three sit next to each other on the same line, because <span> is an inline element and does not break the line.

Div turned into inline

If a block div is given display: inline-block, it behaves like an inline element (sits in a row next to others) while keeping the ability to set width/height and spacing like a block element.
