Experiment description: without normalize.css, every browser sets its own default spacing for headings, font size for inputs and buttons, image borders, and table borders. After including normalize.css these small differences disappear: the h1 heading gets a consistent margin, the button and input inherit the page font instead of the system font, and the table uses border-collapse. Unlike reset.css, normalize.css does not remove styles completely; it only aligns them across browsers, so text and lists still look "normal", just consistent between Chrome, Firefox, and others.
